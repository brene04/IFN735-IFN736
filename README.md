# IFN735-IFN736
IFN735 Capstone Project

A work-integrated learning project between our QUT's Team Innov8 and Philippines Department of Science and Technology (DOST) to create a centralised Competency-Based Human Resource Management System. This is a work-in-progress project which enables automated employee competency profiling, skills-gap analysis, and workforce analytics across 10 integrated modules.

Current Status: Phase 1 prototype in development (Weeks 4–13, Semester 2 2026)
